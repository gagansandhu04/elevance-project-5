# Project 5: Clustered Heatmap Dashboard

## Overview
This project compares app categories using metrics such as ratings, reviews, installs, app size, engagement, and update frequency. A clustered heatmap helps identify patterns and differences between categories.

## Tools Used
Python, Pandas, NumPy, SciPy, Plotly, and Jupyter Notebook.
